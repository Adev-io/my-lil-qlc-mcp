1 Overview

0 Install custom fixture definitions

QLC+ won't know these fixtures until their definitions are in your user fixtures folder.

  1. Copy fixtures/Rainbow-Lights-Smart-2-Pro-RGBWAUV.qxf to C:\Users\<you>\QLC+\Fixtures\ (create the folder if missing).
  2. Restart QLC+ so it loads the new definition.
✅ The Rainbow 10-channel map is Dim · Strobe · R · G · B · W · A · UV · Macro · Speed — rig-verified 2026-06-09 (the vendor's published layout had Strobe at ch 8 and the colours one slot early; the real light puts Strobe at ch 2 and colours at ch 3–8). The def and the generator both use the verified map; nothing to check on the light beyond 10-channel mode.

1 Open the project

Easiest: the desktop QLC+ MCP shortcut launches QLC+ with the show + dashboard. Or manually run:

C:\QLC+4\qlcplus.exe --open punk-rock-show.qxw -p -w

--open <file> loads the project (a bare path is ignored), -p = start in Operate mode, -w = web API on :9999. Then the Virtual Console opens on Page 1 (Level 1 — chill); the R8C8 pad or PgDn/PgUp ramps energy to Page 2 (Level 2 — driving) and Page 3 (Level 3 — full-send), then wraps back. All three pages share the same pad layout; five faders sit to the right of the grid.

2 Address the lights

Set each fixture's physical DMX start address on its display / DIP switches to match the Patch Chart. All on one universe; spacing leaves room for mode changes.

  • Smart 2 Pro RGBWA+UV (10) → 1, 11, 21, 31, 41, 51, 61, 71, 81, 91
  • COLORband T3 BT (2) → 101, 114
  • Intimidator Spot 375Z IRC (2) → 153, 168

3 Art-Net output → your DMX node

Nothing to enable in QLC+ — the show ships with ArtNet output baked in (Line 0, universe 0, broadcast). What follows documents the example rig's node (a Pknight CR011R, verified live 2026-06-09) — your node's IPs and settings will differ, but the shape of the setup (static NIC IP on the node's subnet, node transmit = Art-Net→DMX, universe 0) is the same:

  • PC: USB Ethernet NIC ("Ethernet 3") set static 10.201.6.1 / 255.255.255.0 (elevated: New-NetIPAddress -InterfaceAlias 'Ethernet 3' -IPAddress 10.201.6.1 -PrefixLength 24).
  • Node: Pknight CR011R at 10.201.6.100/24 (fw v2.7). OLED settings: Port universe 0 · Port SubNet 0 · Port Net 0 · Transmit: Artnet -> dmx. Configured on the box itself (no web UI): Menu steps pages, Enter selects, hold Enter 3 seconds to save.
  • Node LEDs: blue LED blinks while Art-Net data flows (fw 2.7 — the printed manual's v2.5 legend is wrong); RJ45 right-side green = data activity, left = link.
⚠️ If the PC NIC's IP ever changes, the ArtNet line index shifts and the rig goes dark. Live fix, no relaunch: browser → localhost:9999/config → Stage row → Output → select [ArtNet] 10.201.6.1. Applies instantly, nothing to save.

4 Launchpad Mini MK3 → MIDI IN only (the MCP drives the LEDs)

QLC+ reads pad presses; it does NOT light the pads. The MCP server's launchpad module owns the Launchpad MIDI output and lights every pad itself over RGB SysEx (idle 50%, the active look at 100%) — see src/launchpad/leds.ts. In QLC+'s Inputs/Outputs ▸ Launchpad, set Input = MIDIIN2 (LPMiniMK3 MIDI) and leave Feedback EMPTY — binding Feedback would fight the module for the MIDI OUT port. Windows' numeric device index can shift on replug/reboot; if presses stop registering, re‑select Input = MIDIIN2. If pads stay dark, reseat the USB and restart the MCP server.

Programmer Mode (set automatically by the MCP — manual fallback below)

  1. Hold the Session button (top‑row round button) and keep holding it.
  2. While still holding Session, press the bottom button of the right‑edge column — the bottom‑right corner button, printed "Stop Solo Mute". (Read the label, not the color — that's the Programmer‑mode selector.)
  3. Release. Confirmation: the green Session light goes OUT and the grid goes dark, then your look pads glow in their colors.
⚠️ Do not tap Session while playing. It drops the Launchpad back to Session mode and the pads go dead (QLC+ stops receiving). Fix: hold Session → Stop Solo Mute again. This is the one thing that knocks the rig out.

Pads glow at 50% in their look colour when idle; the active look in each row jumps to 100% so the live look is unmistakable. The grid reads top rows = openers (whole‑band hues + member spotlights), then verses/choruses, strobes, chasers, and the utility row at the bottom. The physical Launchpad, the QLC+ on‑screen console, and the dashboard all share this exact 8×8, so a look sits in the same spot on all three. See the Launchpad map for what each pad does.

5 Load test (5 min, before doors)

  • Patch: Inputs/Outputs shows fixtures at the right addresses, no overlap warnings.
  • Output: fire WASH ▸ White — the rig lights.
  • Launchpad: a grid pad fires the look and lights up.
  • OSC/dashboard: the dashboard Control tab lists every look; pressing one fires it.
Both surfaces drive the same function, so the Launchpad LED and the dashboard stay in sync.

▶ Rehearse virtually (no lights)

You don't need the rig to practice. QLC+'s Fixture Monitor draws your fixtures on screen and lights them exactly as the real rig would — so you can build and learn looks on the Launchpad with no lights, no Art‑Net node, no DMX.

  1. Launch the show in Operate mode (Step 1): desktop shortcut, or C:\QLC+4\qlcplus.exe --open punk-rock-show.qxw -p -w.
  2. Programmer Mode on the Launchpad (Step 4 — hold Session → Stop Solo Mute).
  3. Top toolbar → Monitor → click 2D View → drag the window beside the main one. Your 14 fixtures appear laid out (pars front, bars mid, heads upstage).
  4. Press pads — looks fire, the fixtures light in the Monitor, and the pad glows bright. That's the full show, virtual.
If the Monitor looks empty or everything's crammed in a corner, the grid size got reset — it's baked at 5 × 4 m; nudge the Size spinner (top of the Monitor) back to roughly 5 × 4 if needed. Heads show as gobo icons; RGB pars/bars are dark squares until a look lights them.

10 How the Launchpad works

One device, three things to know: the physical buttons, how a press travels to the rig, and why the rows are flipped. Read a pad by its position (R#C#), not its colour.

The physical device

  TOP ROUND BUTTONS  (firmware - DEAD in Programmer mode, except Session)

    R1 |R1C1|    |    |    |    |    |    |R1C8|   ( )

    R3 |    |    |    |    |    |    |    |    |   ( )

⚠️ The page-flip pad R8C8 (a grid pad) and Stop Solo Mute (a round scene button used with Session to enter Programmer Mode) are two different buttons — don't confuse them.

How a press reaches the lights

  PHYSICAL                  LAPTOP - QLC+ 4.14.4               WIRELESS
  -------------             --------------------              ------------
  Launchpad pad  --USB-->   MIDIIN2  --> VC button (MIDI) --+
   (Programmer mode)        (port 2)                        |
                                                            +--> Function --> Art-Net U0 --> rig
  Launchpad LED  <--USB--   MCP server --RGB SysEx (winmm)-->        |
   50% idle / 100% active   (owns MIDI OUT; QLC+ = input only)       |
                            OSC :7700 <--Wi-Fi-- iPad dashboard ------+
                                         VC button (OSC)   /look_r#c#

  Both buttons drive the SAME Function, so MIDI and OSC stay in sync.

Use the second MIDI port. If the pads go dead after a replug/reboot, re-select Input = MIDIIN2 and Feedback = MIDIOUT2 in QLC+ Inputs/Outputs.

Why the top row is your colours — row inversion + LED states

  Hardware numbers pads BOTTOM-UP        Show maps them TOP-DOWN (PAD.rows)
  -------------------------------        ---------------------------------
   top row    = highest notes 81-88       R1 (top)    = colours    <- ch 209
   ...            (notes go down)         ...             (go down)
   bottom row = lowest  notes 11-18       R8 (bottom) = control    <- ch 139

  => the row order is REVERSED in software so the TOP row = your main colours.
  LEDs (driven by the MCP server, not QLC+):  idle = 50%  |  active look = 100%.

11 Launchpad map — the energy ladder (3 pages)

The 8×8 grid exactly as it sits on the Launchpad (row 1 = top). The physical Launchpad, the QLC+ on‑screen console, and the dashboard all use this same layout. All three pages share one positional grammar — a pad keeps its song‑moment meaning on every page, just redesigned hotter each level. The show boots on Page 1 (Level 1); press the bottom‑right pad (R8C8) to ramp energy — it cycles Page 1 → 2 → 3 → 1, so you raise a song's intensity without moving your fingers. That corner pad fires no look. (The Mini MK3's top →/← arrows don't transmit on the Programmer port, so a real grid pad owns the switch.) PgDn / PgUp also switch pages. Each button's caption shows its tier + R#C# after the name (e.g. "Band Red L1 R1C2"); idle pads glow at 50% and the active look at 100%. Read by position, not colour.

Every page, same rows: R1‑3 openers (whole‑band hues + member spotlights + texture/crowd), R4‑5 verses/choruses, R6 strobes/hits, R7 chasers, R8 utility (identical on every page — the stable safety layer).

BASE Openers (R1-3) + verses/choruses (R4-5) — full looks. Solo: one base look at a time.STROBE Strobes / hits (R6). Tap = momentary, overlays the running chaser.CHASE Chasers (R7). Solo: one running effect at a time, riding on the base look.CTRL Utility (R8, same on every page): Strobe All · Blinder · Sound Active · Park All · Heads Blackout · Blackout · Full On.

13 Control model

QLC+ stores only one external input per Virtual Console button, so every look has two buttons pointing at the same function: one bound to the Launchpad (MIDI, with LED feedback) and one bound to OSC for the MCP/dashboard. The dashboard's widgets.json only lists the OSC buttons, so each look shows once.

The grid is an energy ladder: three pages of 8×8 that share one positional grammar, each a hotter energy tier. The show boots on Page 1 (Level 1); the bottom-right pad (R8C8) or PgDn / PgUp ramps energy (Page 1 → 2 → 3 → 1, wrapping). Each page's looks sit in non-overlapping row bands:

  • Rows 1-5 · BASE (Solo — one base look at a time): rows 1-3 openers (whole-band hues, member spotlights, texture/crowd) and rows 4-5 verses/choruses. These 40 looks render at three energy levels — P1 deep/cool, P2 saturated, P3 hot + white punch.
  • Row 6 · STROBES (non-solo): momentary hits that overlay a running chaser. Row 7 · CHASERS (Solo — one running effect at a time, riding on the base look). Both escalate slow → medium → fast/hard with the tier.
  • Row 8 · UTILITY — identical on every page (the stable safety layer, does not escalate): Strobe All · Blinder · Sound Active · Park All · Heads Blackout · Blackout · Full On. R8C8 is the energy-up page flip. Plus 5 faders to the right (Pars/Bars/Heads Dim, Strobe Rate, Heads Zoom), visible on every page.

Brightness: every scene drives its own master dimmer to full, so looks light up on their own — including the bars. The three Dim faders on page 2 are overrides: leave them up for full, pull one down to dim that group. Master Dim is the QLC+ GrandMaster (global reducer).

Moving heads aim by stage geometry. Pan/tilt for the heads are computed from your measured stage and performer positions (see rig.json) so the named positions point at real targets: Singer, Guitar, Bass, Drums, the crowd, plus Stage Wash and crossed beams. The motion chases (Head Circle, Audience Sweep, Cross Zigzag, Figure 8, Pan Wave, Tilt Dip) orbit the band and stay on stage; Audience Sweep spins downstage and throws out over the crowd. If a beam misses, note which way it's off and the show is rebuilt with the corrected geometry — no hand-nudging pan/tilt inside QLC+.

OSC paths are / + the lowercase look name (spaces → _) including the pad coordinate, e.g. /red_r1c1. The channel QLC+ matches is the CRC-16 hash of that path — pre-baked, so no Auto-Detect is ever needed.
