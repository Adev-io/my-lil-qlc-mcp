# Punk Rig — Cheat Sheet

*Run the show from the **SIMPLE page** (boots here). Tap **R8C8** to cycle SIMPLE → Page 1 → Page 2.*
*Navigate by **pad position (R#C#)** + name — R1C1 = top-left, R8C8 = bottom-right.*

---

## Per moment, ask 4 things
1. **Wash colour?** → row 4
2. **Heads — where + colour?** → a PRESET sets both
3. **Anything moving?** → row 6
4. **One-shot hit?** → R8C1 Strobe (hold)

## 2 rules
- **One-per-row:** a new press in the same row drops the old one. (Can't make a mess in a row.)
- **Last-press-wins:** newest press owns the light. MOVE only touches pan/tilt — it rides on top of the colour already up.

## The shortcut
**A PRESET = a complete look** (pars + bars + heads + aim + gobo). **Run the whole show from PRESETS.**
Then *optionally*: one MOVE, one WASH colour, one Strobe hit. Done.

## 4 traps (what looks "out of character")
1. **MOVE with no colour → heads go dark.** Fire a PRESET first, then add the move.
2. **"Auto" looks look dead in the monitor** — they only animate on the real rig. Use the **Morph** twins.
3. **Blackout latches** — tap **again** to clear. Never walk away on Blackout.
4. **Don't over-layer** — trust the PRESET; at most one MOVE + one WASH.
